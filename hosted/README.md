# DevSphere — серверная версия

Учебная информационная система образовательного центра. Админка открыта всем посетителям через переключатель роли. Все изменения сохраняются в общей демонстрационной базе D1.

Установка: `npm ci`. Сборка: `npm run build`. Проверка API: `node tests/api.test.mjs` (Node.js 24+).

Миграции: `drizzle/`. Учебные таблицы имеют префикс `demo_`, закрытые записи предыдущей версии не используются публичной админкой.

Для локального просмотра соберите проект и примените новые SQL-миграции к локальной D1 через Wrangler с параметрами `--local --config dist/server/wrangler.json --persist-to .wrangler/state --file <путь-к-миграции>`, затем выполните `npm start`.
