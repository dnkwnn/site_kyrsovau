# DevSphere — образовательный центр

Курсовая работа Коровина Д.Ю., группа ВТ-1-24.

## Облачная версия

Исходники находятся на GitHub. Сервер и общая база данных работают на хостинге Sites (Cloudflare Workers + D1). GitHub Pages не используется, поскольку сайт принимает заявки и хранит общие данные.

- `hosted/home.html` — главная страница.
- `hosted/public/` — стили, JavaScript, изображения.
- `hosted/app/api/` — серверный API.
- `hosted/db/` — схема и обезличенные начальные данные.
- `hosted/drizzle/` — миграции базы.
- `hosted/.openai/hosting.json` — конфигурация хостинга без секретов.

Публичные посетители видят программы, преподавателей и расписание, отправляют заявки и обращения. Данные студентов и обращения доступны администратору после входа через ChatGPT. Разрешённый аккаунт задаётся секретом `ADMIN_EMAIL` на хостинге. Переключение роли не предоставляет серверных прав.

Заявка сохраняется атомарно. При административных изменениях проверяется версия данных, чтобы не затереть свежие заявки.

Для разработки облачной версии нужны Node.js 22.13+ и npm. В папке `hosted`: `npm ci`, `npm run build`, применение миграций к локальной D1 по инструкции `hosted/README.md`, затем `npm run dev`. Локальная и облачная базы независимы.

## Локальная версия Flask

Файлы в корне сохраняют запуск на компьютере через `ЗАПУСТИТЬ_САЙТ.bat`. Либо:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

Адрес: http://127.0.0.1:5000. Локальная версия использует `data.json` и предназначена для демонстрации на компьютере. Не публикуйте её напрямую в интернете.

Локальный `data.json`, секреты, окружения, архивы и временные файлы исключены из Git. Новая база заполняется обезличенными учебными записями. Реальные заявки никогда не выгружаются в репозиторий автоматически.
