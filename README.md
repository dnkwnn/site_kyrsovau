# DevSphere — образовательный центр

Курсовая работа Коровина Д.Ю., группа ВТ-1-24.

Информационная система образовательного центра: курсы, преподаватели, группы, расписание, запись на обучение и обращения.

## Учебный режим

Сайт доступен всем. Чтобы открыть админку, выберите роль **«Администратор»** в верхней панели. Пароль не требуется.

Все посетители работают с общей учебной базой: можно добавлять и удалять записи, отправлять заявки, просматривать обращения, экспортировать JSON и сбрасывать демонстрационные данные. Изменения видны другим посетителям. Используйте только вымышленные данные.

Учебные записи хранятся отдельно от ранее сохранённых закрытых заявок. При одновременных изменениях проверяется версия данных, чтобы случайно не перезаписать свежие записи.

## Структура

- `hosted/home.html` — главная страница.
- `hosted/public/` — стили, скрипты, изображения и анимации.
- `hosted/app/api/` — серверные запросы.
- `hosted/db/` — схема и обезличенные начальные данные.
- `hosted/drizzle/` — миграции общей базы D1.
- Файлы в корне — локальная версия Flask.

## Локальный запуск

Запустите `ЗАПУСТИТЬ_САЙТ.bat` либо выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

Адрес локальной версии: http://127.0.0.1:5000. Она использует локальный `data.json`, который исключён из Git.

Для серверной версии нужны Node.js 22.13+ и npm. В папке `hosted` выполните `npm ci`, затем `npm run build`. Миграции базы находятся в `hosted/drizzle`.
