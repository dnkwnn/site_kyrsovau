# DevSphere — образовательный центр

Курсовая работа Коровина Д.Ю., группа ВТ-1-24.

**Сайт:** https://devsphere-chm.pages.dev

Информационная система образовательного центра: курсы, преподаватели, группы, расписание, запись на обучение и обращения.

## Учебный режим

Сайт доступен всем. Чтобы открыть админку, выберите роль **«Администратор»** в верхней панели. Пароль не требуется.

Все посетители работают с общей учебной базой: можно добавлять и удалять записи, отправлять заявки, просматривать обращения, экспортировать JSON и сбрасывать демонстрационные данные. Изменения видны другим посетителям. Используйте только вымышленные данные.

Учебные записи хранятся отдельно от ранее сохранённых закрытых заявок. При одновременных изменениях проверяется версия данных, чтобы случайно не перезаписать свежие записи.

## Структура

- `cloudflare/public/` — главная страница, стили, скрипты и изображения.
- `cloudflare/api.ts` — серверный API общей учебной базы.
- `cloudflare/worker.ts` — обработчик запросов Pages Functions.
- `cloudflare/db/` — схема и обезличенные начальные записи.
- `cloudflare/wrangler.jsonc` — настройки привязки D1, без секретов.
- `cloudflare/build.mjs` — сборка для публикации.
- `hosted/` — предыдущая серверная реализация и зависимости сборщика.
- Файлы в корне — локальная версия Flask.

Для сборки опубликованной версии сначала установите зависимости в `hosted` командой `npm ci`, затем из корня выполните `node cloudflare/build.mjs`. Для публикации используется `wrangler pages deploy dist --project-name devsphere --branch main` из папки `cloudflare` после авторизации в аккаунте владельца. Схема D1: `cloudflare/db/schema.sql`.

## Локальный запуск

Запустите `ЗАПУСТИТЬ_САЙТ.bat` либо выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe server.py
```

Адрес локальной версии: http://127.0.0.1:5000. Она использует локальный `data.json`, который исключён из Git.

Для серверной сборки нужны Node.js 22.13+ и npm. Для проверки API на Node.js 24+ выполните `node cloudflare/tests/api.test.mjs`.
