# API сайта DevSphere

Сервер запускается командой:

```powershell
python server.py
```

После запуска сайт доступен по адресу `http://127.0.0.1:5000`, а проверка API — по адресу `http://127.0.0.1:5000/api/health`.

## Основные маршруты

| Метод | URL | Назначение |
|---|---|---|
| GET | `/api/health` | Проверка работы сервера |
| GET | `/api/data` | Получить все данные сайта |
| PUT | `/api/data` | Сохранить полный набор данных |
| POST | `/api/reset` | Вернуть демонстрационные данные |
| GET | `/api/<entity>` | Получить список записей |
| POST | `/api/<entity>` | Создать запись |
| GET | `/api/<entity>/<id>` | Получить одну запись |
| PUT | `/api/<entity>/<id>` | Изменить запись |
| DELETE | `/api/<entity>/<id>` | Удалить запись |

Допустимые значения `entity`: `students`, `teachers`, `courses`, `groups`, `enrollments`, `schedules`, `feedback`.

## Пример создания студента

```json
{
  "name": "Петров Петр Петрович",
  "birthDate": "2006-01-15",
  "phone": "+7 (999) 000-00-00",
  "email": "petrov@example.ru",
  "regDate": "2026-10-08"
}
```

Данные сохраняются сервером в файле `data.json`. Файл создаётся автоматически при первом запуске.
