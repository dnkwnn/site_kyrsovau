# DevSphere API — учебная версия

Общая демонстрационная база доступна всем посетителям. Авторизация не требуется. Используйте вымышленные данные.

- `GET /api/health` — состояние сервера.
- `GET /api/data` — учебные записи и текущая версия `_version`.
- `POST /api/apply` — запись на курс: `name`, `email`, `phone`, `courseId`.
- `POST /api/feedback` — обращение: `name`, `email`, `message`.
- `PUT /api/data` — сохранение изменений. Нужна `_version` из последней загрузки; при конфликте возвращается HTTP 409.
- `POST /api/reset` — восстановление обезличенных учебных записей.

Учебные таблицы `demo_records`, `demo_state`, `demo_receipts` отделены от ранее сохранённых закрытых данных. Сброс учебной базы не изменяет закрытые таблицы.

Запись студента и заявки выполняется одной транзакцией. Данные проверяются на сервере, номера записей назначаются автоматически.
