# API облачной версии

Сервер: `hosted/app/api/[...path]/route.ts`. База: Cloudflare D1.

- `GET /api/health` — состояние API.
- `GET /api/data` — публичный каталог; студентские данные и обращения возвращаются только администратору.
- `POST /api/apply` — запись на курс: `name`, `email`, `phone`, `courseId`. Создание студента и заявки выполняется одной транзакцией.
- `POST /api/feedback` — обращение: `name`, `email`, `message`.
- `PUT /api/data` — сохранение административных изменений, требуется `_version` из последней загрузки. При конфликте: HTTP 409.
- `POST /api/reset` — восстановление обезличенных учебных записей, только администратор.

Вход администратора определяется на сервере по подтверждённой платформой личности ChatGPT и секрету `ADMIN_EMAIL`. Публичные запросы не могут менять каталог, читать обращения или сбрасывать базу. Ошибки форм возвращают HTTP 400, отсутствие прав — 403.

## Локальная версия Flask (для демонстрации)

# API сайта DevSphere

Сервер запускается командой:

```powershell
python server.py
```

После запуска сайт доступен по адресу `http://127.0.0.1:5000`, а проверка API — по адресу `http://127.0.0.1:5000/api/health`.

## Основные маршруты

| Метод | URL | Назначение |
|---|---|---|
| GET | `/api/health` | Проверка работы сервера |
| GET | `/api/data` | Получить все данные сайта |
| PUT | `/api/data` | Сохранить полный набор данных |
| POST | `/api/reset` | Вернуть демонстрационные данные |
| GET | `/api/<entity>` | Получить список записей |
| POST | `/api/<entity>` | Создать запись |
| GET | `/api/<entity>/<id>` | Получить одну запись |
| PUT | `/api/<entity>/<id>` | Изменить запись |
| DELETE | `/api/<entity>/<id>` | Удалить запись |

Допустимые значения `entity`: `students`, `teachers`, `courses`, `groups`, `enrollments`, `schedules`, `feedback`.

## Пример создания студента

```json
{
  "name": "Петров Петр Петрович",
  "birthDate": "2006-01-15",
  "phone": "+7 (999) 000-00-00",
  "email": "petrov@example.ru",
  "regDate": "2026-10-08"
}
```

Данные сохраняются сервером в файле `data.json`. Файл создаётся автоматически при первом запуске.
