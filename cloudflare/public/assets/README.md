# Иллюстрация DevSphere

## Вращающаяся фигура на зелёной полосе — 16.10.2026

Файлы `code-navigator-cutout.png` и `code-navigator-cutout.webp` содержат фигуру с прозрачным фоном. Подготовлены встроенным инструментом imagegen из исходной иллюстрации. Вращение на 360° выполняется CSS-анимацией за 28 секунд. Точки — отдельные HTML-элементы с пульсацией в CSS. Кнопка «Пауза» останавливает оба эффекта. При системной настройке уменьшения движения анимации отключаются.

Запрос редактирования:

> Precisely extract only the complete central metal gyroscope/rings, ivory code symbol, green needle and their small metal spheres as one isolated cutout. Remove all dark green background, technical grid, dots and drafting circles, including the background visible through every hole between the rings. Keep the sculpture's geometry, angle, reflections, colors and proportions. Actual transparent background and internal holes. Centered square canvas, no floor, no shadows outside the object, no text.

Уточнение:

> Clean all stray speckles, halos and opaque fragments outside the sculpture and between the rings. Preserve the metal rings, code symbol, needle, orientation and colors. Crisp antialiased object edges on a fully transparent background.
